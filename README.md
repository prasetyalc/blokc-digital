# 🚀 BlokC Digital

BlokC Digital adalah website lingkungan warga modern yang dirancang untuk menampilkan layanan digital secara profesional, cepat, dan responsif. Website ini mengutamakan desain minimalis, performa tinggi, serta pengalaman pengguna yang nyaman di berbagai ukuran layar.

👉 https://blokc-digital.vercel.app/

## 🚀 Menjalankan Secara Lokal

Clone repository terlebih dahulu.

```bash
git clone https://github.com/username/blokc-digital.git
```

Masuk ke folder project.

```bash
cd blokc-digital
```

Kemudian buka file `index.html` menggunakan browser, atau gunakan Live Server di Visual Studio Code.
